# Day 2 - Resource Groups and Azure Organization

## Azure Hierarchy 

Azure Account
→ Subscription
→ Resource Group
→ Resources

## What is a Resource Group?

A Resource Group is a logical container that holds Azure resources.

## Why are Resource Groups important?

- Organization
- Permissions managemnt
- Cost tracking
- Easier deployments
- Easier cleanup
