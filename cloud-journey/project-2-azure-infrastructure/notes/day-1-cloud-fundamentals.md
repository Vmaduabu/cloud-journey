# Day 1 - Cloud Fundamentals

## What is Cloud Computing?
Cloud computing is the delivery of computing resources over the internet instead of maintaining physical infrastructure.

# Why do companies use cloud computing?
- Scalability
- Flexibility
- Reliability
- Reduced upfront costs
- Faster deployments

## Core Azure Service Categories

### Compute
Provides processing power for applications and services.

### Networking
Connects resources and controls communication.

### Storage 
Stores files, backups, and application data.

### Identity
Manages users, authentication, and permissions.

## Azure Services Explored Today
- Cost Management + Billing
- Resource Groups
- Virtual Networks
- Storage Accounts
- Microsoft Entra ID
- Azure Monitor

## Biggest Takeaways
Cloud platforms provide the infrastructure and services organizations need without requiring them to manage physical hardware.
